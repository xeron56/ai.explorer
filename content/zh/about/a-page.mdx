# 这是一个示例页面

欢迎来到示例页面！这是一个用于演示 Nextra 功能的简单页面。

## 功能展示

在这里你可以展示各种 Nextra 特性：

- 📝 Markdown 和 MDX 支持
- 🎨 内置主题样式
- 🔍 全文搜索功能
- 🌙 暗色模式支持

## 如何使用

这个页面展示了如何创建一个简单的关于页面。你可以根据需要添加更多内容：

```mdx
# 标题

这里是内容...

## 子标题

更多详细信息...
```

## 自定义内容

你可以自由编辑这个页面，添加你自己的内容和组件。Nextra 支持丰富的自定义选项，让你的文档站点更加个性化。
