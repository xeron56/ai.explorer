Layer normalization removes a feature-wise mean and variance, then re-injects
learnable scale $\gamma$ and shift $\beta$:

$$
\operatorname{LN}(x) = \gamma \odot \frac{x - \mu(x)}{\sqrt{\sigma^2(x) + \epsilon}} + \beta
$$

where the statistics are computed across the **feature** axis, not the batch
axis. This makes LayerNorm independent of batch size, which is exactly what you
want for variable-length sequence models.

## Pre-norm vs. post-norm

The original Transformer applied LayerNorm *after* the residual addition. Most
modern stacks apply it *before* the sub-layer:

$$
x_{\ell+1} = x_\ell + \operatorname{Sublayer}(\operatorname{LN}(x_\ell))
$$

Pre-norm is more forgiving at large depth because the residual path is the
identity — gradients can travel from layer $L$ back to layer $1$ without ever
passing through a normalization step.

## A quick stability sketch

Without normalization, each sub-layer adds a vector whose norm can grow
linearly with depth. After $L$ layers the activation norm is $O(\sqrt{L})$. With
LayerNorm in the pre-norm position, the normalization forces the sub-layer
input to unit-ish scale before it sees any non-linearity, so each contribution
is bounded.

```python
class LayerNorm(nn.Module):
    def __init__(self, dim, eps=1e-5):
        super().__init__()
        self.gamma = nn.Parameter(torch.ones(dim))
        self.beta = nn.Parameter(torch.zeros(dim))
        self.eps = eps

    def forward(self, x):
        mu = x.mean(-1, keepdim=True)
        var = x.var(-1, keepdim=True, unbiased=False)
        return self.gamma * (x - mu) / (var + self.eps).sqrt() + self.beta
```

## RMSNorm: less is more

Recent models drop the mean subtraction entirely:

$$
\operatorname{RMSNorm}(x) = \gamma \odot \frac{x}{\sqrt{\frac{1}{d}\sum_i x_i^2 + \epsilon}}
$$

It's a cheaper kernel, removes the $\beta$ parameter, and in practice matches or
beats LayerNorm on large language models.
